## 🎯 Google Apps Script의 장점

| 장점 | 설명 |
|------|------|
| **📱 모바일 지원** | Google Sheets 앱에서 언제 어디서나 접근 |
| **☁️ 클라우드 기반** | 설치 불필요, 자동 저장 |
| **🆓 완전 무료** | Google 계정만 있으면 됨 |

| **💾 자동 저장** | 결과가 자동으로 저장됨 |

## 🚀 빠른 시작 (5분 완성!)

### 1단계: Google Sheets 생성

1. [Google Sheets](https://sheets.google.com) 접속
2. **새 스프레드시트** 생성
3. 제목: "MACD 백테스팅"

### 2단계: Apps Script 열기

1. 메뉴: **확장 프로그램** > **Apps Script**
2. 새 탭이 열림

### 3단계: 코드 붙여넣기

1. 기본 코드 전체 삭제
2. `Code.gs` 파일 내용 복사
3. Apps Script 에디터에 붙여넣기
4. **저장** (💾 아이콘 또는 `Ctrl+S`)

### 4단계: 권한 승인

1. **실행** 버튼 (▶️) 클릭
2. "권한 검토" 클릭
3. Google 계정 선택
4. **고급** > **[프로젝트명](으)로 이동** 클릭
5. **허용** 클릭

> ⚠️ "확인되지 않은 앱" 경고가 뜨는 이유:
> - 직접 만든 스크립트라서 Google이 검증하지 않음
> - 본인만 사용하므로 안전함
> - 코드를 직접 볼 수 있어서 투명함

### 5단계: 스프레드시트로 돌아가기

1. Apps Script 탭 닫기
2. Google Sheets로 돌아오기
3. **페이지 새로고침** (F5)
4. 상단 메뉴에 **📈 백테스팅** 메뉴 생성됨!

## 📋 사용 방법

### 최초 설정 (한 번만)

1. 메뉴: **📈 백테스팅** > **⚙️ 템플릿 생성**
2. 3개 시트 자동 생성:
   - **설정**: 파라미터 입력
   - **결과**: 백테스팅 결과
   - **데이터**: 상세 데이터

### 백테스팅 실행

#### 1. 파라미터 설정 ("설정" 시트)

| 파라미터 | 기본값 | 설명 |
|---------|--------|------|
| 티커 심볼 | AAPL | 주식 티커 (예: NVDA, TSLA) |
| 단기 이동평균 (MA1) | 10 | 짧은 이동평균 기간 |
| 장기 이동평균 (MA2) | 21 | 긴 이동평균 기간 |
| 시작 날짜 (일 전) | 730 | 몇 일 전부터 (730일 = 2년) |
| 초기 자본 ($) | 20000 | 시작 자금 |

**예시:**
```
티커 심볼:          NVDA
MA1:               10
MA2:               21
시작 날짜:          365  (1년)
초기 자본:          50000
```

#### 2. 실행

1. 메뉴: **📈 백테스팅** > **🚀 백테스트 실행**
2. "데이터 다운로드 중..." 메시지 → **확인**
3. 잠시 대기 (10-30초)
4. "백테스팅 완료!" 메시지

#### 3. 결과 확인 ("결과" 시트)

```
📊 NVDA MACD 백테스팅 결과
MA10 / MA21

┌─────────────────────┬──────────────┐
│ 지표                 │ 값           │
├─────────────────────┼──────────────┤
│ 🎯 총 수익률         │ 125.45%      │
│ 📈 매수&보유 수익률   │ 98.32%       │
│ 💰 초과 수익         │ 27.13%       │
│                     │              │
│ 📊 샤프 비율         │ 1.87         │
│ 📉 최대 낙폭         │ -18.45%      │
│ 🎲 승률             │ 58.3%        │
│ 🔄 총 거래 횟수      │ 48회         │
│                     │              │
│ 💵 초기 자본         │ $20,000      │
│ 💵 최종 자산         │ $45,090      │
│ 💵 손익             │ $25,090      │
└─────────────────────┴──────────────┘
```

#### 4. 차트 생성 (선택사항)

1. 메뉴: **📈 백테스팅** > **📊 차트 생성**
2. 2개 차트 자동 생성:
   - **가격 & 이동평균** (선 그래프)
   - **포트폴리오 가치** (영역 차트)

## 📱 모바일 사용 방법

### 1. Google Sheets 앱 설치

- **iOS**: [App Store](https://apps.apple.com/app/google-sheets/id842849113)
- **Android**: [Google Play](https://play.google.com/store/apps/details?id=com.google.android.apps.docs.editors.sheets)

### 2. 스프레드시트 열기

1. Google Sheets 앱 실행
2. "MACD 백테스팅" 파일 선택

### 3. 파라미터 수정

1. "설정" 시트로 이동
2. 셀 탭하여 값 수정
   - 티커: `AAPL` → `TSLA`
   - MA1: `10` (그대로)
   - MA2: `21` (그대로)

### 4. 백테스트 실행 (모바일)

**⚠️ 중요**: 모바일에서는 메뉴가 제한됩니다.

**방법 1: 웹 브라우저 사용 (권장)**

1. 모바일 크롬/사파리에서 접속:
   ```
   https://docs.google.com/spreadsheets/d/[YOUR_SHEET_ID]
   ```
2. 우측 상단 **⋮** > **데스크톱 사이트**
3. **📈 백테스팅** 메뉴 표시됨
4. **🚀 백테스트 실행**

**방법 2: 미리 실행 후 확인만**

1. PC에서 백테스트 실행
2. 모바일에서 결과만 확인
3. 파라미터 수정 후 다시 PC에서 실행

### 5. 결과 확인 (모바일)

1. "결과" 시트로 이동
2. 스크롤하여 지표 확인
3. 핀치 줌으로 확대/축소
4. 차트도 확인 가능!

## 🔧 고급 설정

### 다른 데이터 소스 사용

Yahoo Finance API가 작동하지 않을 경우:

#### 방법 1: Google Finance 함수

1. "데이터" 시트에서 수동 입력:
   ```
   =GOOGLEFINANCE("AAPL", "close", DATE(2022,1,1), DATE(2024,1,1), "DAILY")
   ```

2. `Code.gs`의 `fetchStockData` 함수 수정

#### 방법 2: 수동 데이터 입력

1. Yahoo Finance 웹사이트에서 CSV 다운로드
2. "데이터" 시트에 붙여넣기
3. 코드에서 데이터 읽기 로직 수정

### 실행 시간 제한 해결

Google Apps Script는 **6분 실행 제한**이 있습니다.

**해결책:**

1. **데이터 기간 축소**:
   - 730일 → 365일로 변경

2. **데이터 캐싱**:
   - 한 번 다운로드한 데이터를 시트에 저장
   - 재실행 시 저장된 데이터 사용

3. **트리거 사용**:
   - Apps Script에서 "트리거" 설정
   - 매일 자동 실행

## 💡 활용 팁

### 1. 여러 티커 비교

1. 스프레드시트 복사 (Ctrl+D)
2. 각각 다른 티커 설정
3. 결과 비교

### 2. 파라미터 최적화

1. "설정" 시트에서 다양한 MA 조합 시도:
   - MA5 / MA15
   - MA10 / MA21
   - MA20 / MA50

2. "결과" 시트에서 가장 좋은 조합 찾기

### 3. 자동 업데이트

**트리거 설정:**

1. Apps Script 에디터 열기
2. 좌측: **트리거** (⏰ 아이콘)
3. **+ 트리거 추가**
4. 설정:
   - 함수: `runBacktest`
   - 이벤트 소스: **시간 기반**
   - 빈도: **일간** (매일 오전 9시)

5. **저장**

→ 매일 자동으로 백테스트 업데이트!

### 4. 알림 설정

`Code.gs` 수정:

```javascript
function runBacktest() {
  // ... 기존 코드 ...

  // 결과가 좋으면 이메일 알림
  if (metrics.totalReturn > 10) {  // 10% 이상 수익
    MailApp.sendEmail({
      to: Session.getActiveUser().getEmail(),
      subject: `📈 ${ticker} 수익률: ${metrics.totalReturn.toFixed(2)}%`,
      body: `백테스팅 결과를 확인하세요!`
    });
  }
}
```

## 🛠️ 문제 해결

### 1. "권한 검토" 오류

**원인**: 처음 실행 시 권한 필요

**해결**:
1. **고급** 클릭
2. **[프로젝트명](으)로 이동**
3. **허용**

### 2. "데이터 다운로드 실패"

**원인**: Yahoo Finance API 차단 또는 티커 오류

**해결**:
1. 티커 심볼 확인 (대문자로 입력)
2. 잠시 후 다시 시도
3. 대안: Google Finance 함수 사용

### 3. "실행 시간 초과"

**원인**: 6분 제한

**해결**:
1. 데이터 기간 축소 (730일 → 365일)
2. 코드 최적화

### 4. 모바일에서 메뉴 안 보임

**해결**:
1. 모바일 브라우저로 접속
2. "데스크톱 사이트" 요청
3. 또는 PC에서 실행 후 결과만 확인

| H | 포트폴리오 가치 |

## 🔒 보안 및 프라이버시

### ✅ 안전한 점:

1. **Google 계정 내에서만 작동**
   - 다른 사람은 접근 불가 (공유하지 않는 한)

2. **로컬 계산**
   - 백테스팅은 Google 서버에서 실행
   - 하지만 귀하의 Google 계정 내부

3. **투명한 코드**
   - 모든 코드를 직접 볼 수 있음
   - 숨겨진 기능 없음

4. **최소한의 외부 통신**
   - Yahoo Finance에서 공개 데이터만 다운로드
   - 전송 정보: 티커, 날짜

### ⚠️ 주의사항:

1. **스프레드시트 공유 조심**
   - 공유 설정: "나만 보기" 권장
   - 링크 공유 시 "편집자" 권한 주지 말기

2. **API 할당량**
   - Google Apps Script: 일일 제한 있음
   - 과도한 실행 자제

3. **개인 정보**
   - 실제 거래 계좌 정보 입력 금지
   - 백테스팅용 가상 자본만 사용

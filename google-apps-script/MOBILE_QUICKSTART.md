## 🎯 5분 완성 (모바일 전용)

### 📱 1단계: 앱 설치

**Google Sheets 앱 다운로드:**

- **iPhone**: App Store에서 "Google Sheets" 검색
- **Android**: Play 스토어에서 "Google Sheets" 검색

### 💻 2단계: PC에서 초기 설정 (한 번만)

> ⚠️ 최초 설정은 PC가 필요합니다 (5분)

1. PC에서 [Google Sheets](https://sheets.google.com) 접속
2. 새 스프레드시트 생성: "MACD 백테스팅"
3. **확장 프로그램** > **Apps Script**
4. `Code.gs` 파일 내용 붙여넣기
5. 저장 후 권한 승인
6. Sheets로 돌아와서 새로고침
7. **📈 백테스팅** > **⚙️ 템플릿 생성**

**완료!** 이제 모바일에서만 사용 가능합니다.

## 📱 모바일 사용법

### 방법 1: 앱 + 브라우저 (추천)

#### 파라미터 수정 (앱)

1. **Google Sheets 앱** 실행
2. "MACD 백테스팅" 파일 열기
3. **"설정"** 시트로 이동
4. 값 수정:
   ```
   티커 심볼:  TSLA  (탭하여 수정)
   MA1:        10
   MA2:        21
   초기 자본:   30000
   ```

#### 백테스트 실행 (브라우저)

1. **모바일 Chrome/Safari** 열기
2. 주소창에 입력:
   ```
   sheets.google.com
   ```
3. "MACD 백테스팅" 파일 열기
4. 우측 상단 **⋮** (점 3개)
5. **데스크톱 사이트** 체크
6. 상단 메뉴에서 **📈 백테스팅** > **🚀 백테스트 실행**
7. 20-30초 대기

#### 결과 확인 (앱)

1. **Google Sheets 앱**으로 돌아가기
2. **"결과"** 시트로 이동
3. 수익률, 샤프 비율 등 확인
4. 핀치 줌으로 확대

## ❓ 모바일 FAQ

### Q1. 앱에서 메뉴가 안 보여요

**A**: Apps Script 메뉴는 앱에서 제한됨
- **해결**: 모바일 브라우저 → 데스크톱 사이트 사용

### Q2. 실행이 너무 느려요

**A**: 모바일 네트워크 영향
- **해결**:
  1. WiFi 연결
  2. 데이터 기간 축소 (730일 → 365일)

### Q3. 차트가 안 보여요

**A**: 모바일 앱에서 차트 지원 제한적
- **해결**: 앱에서 차트 탭 → 스크롤하여 확인

### Q4. 편집이 불편해요

**A**: 작은 화면 제약
- **해결**:
  1. 가로 모드 사용
  2. 확대 후 편집
  3. 자주 쓰는 값은 드롭다운 메뉴로 설정
